## 对照我们自己的规格

- 侧栏：歌曲 / 曲风 / 专辑 / 艺术家 / 文件夹 / 音乐库 / 设置 + 分隔线 + 歌单（Salt 用彩色小图标；我们用自绘 `Glyph` 线性图标，避免复制素材）。
- 主区：大标题 + 数量/统计 + 排序/筛选/搜索；行内封面 48、标题 + 音质徽标、艺术家、专辑、时长，当前行高亮并显示勾选。
- 播放栏：封面 + 标题/艺术家 · 循环/上一首/播放/下一首/队列 · 更多 · 输出采样率 · 音量 · 静音。
- 播放页：模糊封面背景 + 左封面右歌词；歌词分行、逐字扫过、当前行高亮。
- 音频设置：输出 API 选择、独占开关、抖动、音量 dB、可选电平表。

差异：Sonora 额外有在线音源（搜索/歌单/推荐/登录），Salt 是纯本地播放器；版权与账号相关界面不参考 Salt。
